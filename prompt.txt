You are a senior frontend engineer specializing in React animations and modern UI design.

Your task is to build a modern wedding invitation landing page hero section with animated image columns and a blurred center content card.

Tech stack:
- React (Vite)
- TailwindCSS
- Framer Motion for animations
- Fully responsive
- Clean reusable component structure

Goal:
Create a premium hero section where multiple columns of images move vertically in alternating directions, with a blurred center card that highlights the main title.

Layout description:

1. Full screen hero section
Height: 100vh
Width: 100%

Background: light neutral background

2. Animated Image Columns
Display multiple vertical columns of small images across the screen.

Rules:
- Each column contains stacked images
- Images have rounded corners
- Images are portrait rectangles
- Example size: 120px x 160px
- Gap between images: 24px

Animation behavior:
- Columns move vertically in infinite loops
- Alternate directions:

Column 1 → move UP
Column 2 → move DOWN
Column 3 → move UP
Column 4 → move DOWN
Column 5 → move UP

Animation speed should be slow and smooth (luxury feeling).

The animation should loop infinitely.

Columns should have slightly different speeds to create a subtle parallax depth effect.

Example speeds:
column1: 20s
column2: 25s
column3: 18s
column4: 22s
column5: 26s

3. Edge Fade Effect
Images should fade in and fade out at the top and bottom of the screen.

This should be implemented using CSS mask-image or gradient overlays.

Top and bottom edges should gradually reduce opacity so images appear and disappear smoothly instead of abruptly entering and leaving the screen.

Example concept:

transparent → visible → visible → transparent

Properties:

The center card should blur the moving image background behind it using backdrop-blur.
